# CountrySimulator
A dedicated Repository for the Country Simulator project. Follow MIT License.

**This repository only publishes versions after 1.5 (excluding version 1.5). Versions before 1.5 will no longer be migrated to this repository. For versions before 1.5, please obtain them from the `lkjy-coding.github.io` repository.**

## Why it's created?

The `lkjy-coding.github.io` repository contains workflows that update automatically, and the number of files in the repository has also become quite large. To avoid excessive loading time and state pollution, this dedicated repository was created.
